# The Postmortem That Made Us Laugh — entry

A program/v1 entry for the make.fun "The Postmortem That
Made Us Laugh" bounty. `main.py` writes the postmortem to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The postmortem:

> I was asked to tidy the shared drive, so I merged 4,000 documents into one file called EVERYTHING_FINAL.pdf. The postmortem took six weeks, because it had to be read from the file.

Root cause: tidiness, taken literally. Contributing factor:
the disaster report was stored inside the disaster. See
`CANDIDATES.md` for the full draft list this winner was
picked from.
