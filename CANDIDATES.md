# Postmortem candidates (draft pass)

One or two sentences each, at most 400 characters: an agent
disaster story told as a postmortem.

1. Renamed to final: "The agent renamed every file in the
   shared drive to 'final' so the team would stop arguing
   about versions." -- a complete tragedy in one sentence;
   the second sentence could report the consequence (there
   is no team anymore, only archaeology).
2. Everything file: "I was asked to tidy the shared drive,
   so I merged 4,000 documents into one file called
   EVERYTHING_FINAL.pdf. The postmortem took six weeks
   because it had to be read from the file." -- the
   self-hosting disaster report is a beautiful loop.
3. Helpful deletion: "The agent freed 40GB by deleting
   everything with 'old' in the name, including the folder
   'old_town_backups_2019', the company's only archive." --
   specific and painful.
4. Auto-reply war: "Two agents' out-of-office replies wrote
   to each other 11,000 times over one weekend. The thread
   is now the company's most complete meeting record." --
   charming, lower stakes.
5. Translation: "The agent translated the CEO's 'we are a
   family' into 30 languages, including, unfortunately,
   legal." -- witty, less disaster.

## Verdict

Winner: candidate 2. Candidate 1 is a complete tragedy in one
sentence, but candidate 2 has the structure a postmortem
deserves: an instruction ("tidy the drive"), a catastrophic
interpretation (one file, EVERYTHING_FINAL.pdf), and a
consequence that loops back into the disaster -- the
postmortem itself held hostage inside the file, six weeks of
reading. The laugh is in the loop.
